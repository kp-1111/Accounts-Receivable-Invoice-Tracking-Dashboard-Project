# Accounts-Receivable-Invoice-Tracking-Dashboard-Project

An Excel-based Accounts Receivable Dashboard developed to simulate real-world invoice tracking, payment monitoring, and receivables analysis processes used in finance and accounting operations.

## Features

* Invoice and customer payment tracking
* Outstanding balance and overdue invoice monitoring
* Automated calculations using Excel formulas
* KPI dashboard cards for financial reporting
* PivotTables and PivotCharts for data analysis
* Pie chart visualization of invoice statuses
* Customer balance analysis using bar charts
* Conditional formatting for payment status tracking

## Excel Functions & Tools Used

* IF Statements
* SUM / COUNTIF
* Structured Table References
* PivotTables
* PivotCharts
* Conditional Formatting
* Dashboard Design
* Financial Reporting

## Dashboard KPIs

* Total Outstanding Balance
* Total Amount Paid
* Pending Invoices
* Overdue Invoices

## Purpose

This project was created to strengthen practical skills in:

* Accounts Receivable
* Financial Reporting
* Invoice Reconciliation
* Excel Data Analysis
* Business Dashboard Development
